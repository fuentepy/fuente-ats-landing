# Capturas del producto (datos de ejemplo)

Imágenes de la sección «Seguí el avance de cada búsqueda». Son **páginas reales de la aplicación** renderizadas con datos
sintéticos (nombres de pila con inicial de apellido, «Cliente de ejemplo A/B», correos `example.invalid`); no hay personas,
clientes ni empresas reales. Se generan con el arnés `qa/capturas` de `fuentepy/fuente-ats` (rama `qa/capturas-web`).

Tema oscuro (el que el producto muestra por defecto). Para cada pantalla:
- `*-oscuro-1600.webp` y `*-oscuro-800.webp`: ventana completa recortada al contenido (1600×914 y 800×457).
- `*-oscuro-movil-900.webp`: solo el área de contenido, sin barra lateral (900×617), para pantallas angostas.
